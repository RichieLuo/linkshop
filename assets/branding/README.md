# LinkShop branding

`linkshop-fox-logo.png` is the wide fox-and-wordmark banner used at the top of the README. It is displayed centered at 560 pixels, following the shared Shop README layout.

`linkshop-fox.png` is the application artwork used to generate the normalized window, taskbar and embedded Windows EXE icons. The README banner and application icon have separate presentation roles. See [the shared branding conventions](../../docs/branding.md).
